# Decks

Three pitch decks, one per audience, same look. Each folder holds the deck's
slide sources: `project/deck.json` (order, sections, typefaces) and one HTML
section per slide under `project/slides/`, each a 1920×1080 canvas with inline
styles and inline SVG scenes. The live, presentable versions were published as
Claude Slides artifacts and export to PPTX and PDF from there; these sources are
the editable originals.
